# Инструменты и панель

Клиент не сообщает серверу, из какого проекта пришёл вызов, поэтому проект открывается явно:
`workspace_open(name)` возвращает хэндл `ws`, он передаётся первым аргументом во все остальные инструменты.

## Инструменты модели

| инструмент | что делает |
|---|---|
| `workspaces_list()` | проекты из реестра: имя, режим, описание |
| `workspace_open(name, mode="ro")` | хэндл, срок его жизни, политика и BRIEF проекта |
| `ls`, `tree`, `find` | каталог, дерево (глубина до 4), поиск по маске |
| `grep(ws, pattern, path, glob)` | регулярное выражение по текстовым файлам; ripgrep, без него — обход на Python |
| `read(ws, path, offset, limit)` | текст с номерами строк, не больше `max_read_kb` |
| `extract(ws, path)` | текст из PDF, DOCX, XLSX (листы — CSV) |
| `write`, `edit` | только в `rw`, не в `.git`; `edit` заменяет ровно одно вхождение; перед изменением — копия |
| `publish(ws, paths)` | показать файлы человеку карточкой: копия в перевалку, содержимое модели не возвращается |
| `panel()` | панель для человека; в клиентах без MCP Apps — текстовая сводка |

Хэндл истёк или сервер перезапущен — инструмент отвечает «вызови workspace_open заново», модель так и делает.

## `publish`: файл → карточка в чате

1. `publish` копирует файлы в каталог перевалки (`[outbox]`), проверки путей — как у `read`; режим `ro` разрешён.
2. Модель через мост Desktop: `device_request_folder_access(корень)` — один раз в чате (ты подтверждаешь),
   затем `device_stage_files(пути)` и `SendUserFile(display="render")`.
3. Содержимое через модель не проходит. Копии удаляются через `ttl_minutes`, карточка остаётся в чате.

## Панель

«Открой панель wshub» в чате, начатом в Desktop. Вкладки:

1. **Обзор** — проверки doctor, живые процессы и «код новее запущенного», лимиты журнала и копий, перевалка.
2. **Проекты** — добавить, изменить, удалить; выбор папки, проверка BRIEF, предпросмотр масок deny.
3. **Сессии** — открытые хэндлы всех процессов, отзыв, запрет проекта и его снятие.
4. **Журнал** — последние записи с фильтрами (ошибки, изменения, проект, инструмент).
5. **Копии** — сравнение с текущей версией и восстановление.

Инструменты панели (`panel_*`) помечены `visibility: ["app"]` — хост не показывает их модели.
Каждое изменение требует одноразовый код (10 минут), его выдаёт только `panel_data`.

## Несколько процессов

Desktop может держать несколько процессов wshub. Каждый пишет `run/<pid>.json` (старт, версия кода, хэндлы без
токенов, последний вызов). Отзыв хэндла — файл `revoked`, запрет проекта — `blocked.json`; их проверяют все процессы
на каждом вызове. Реестр подхватывается по mtime.

## CLI

```
wshub                     MCP-сервер (stdio); его запускает Claude Desktop
wshub setup               подключить к Desktop: конфиг, реестр, первый проект, перевалка
wshub doctor              ripgrep, реестр, пути, запись в Desktop, процессы и «устарел», журнал, копии, перевалка
wshub update              обновить; затем перезапуск Desktop
wshub uninstall [--purge] убрать из Desktop; --purge — ещё реестр и состояние
wshub outbox set <путь>   папка перевалки
wshub outbox clean        удалить каталоги перевалки wshub
wshub --version           версия и коммит
```
